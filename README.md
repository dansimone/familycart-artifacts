# familycart-artifacts

Public static assets for the **Family Cart** iOS app (private app repo:
`dansimone/familycart`). Served via GitHub Pages.

## Contents
- `extended-catalog.json.gz` — extended grocery catalog (~50k popular items,
  lean `[[name, category], ...]`), generated by `scripts/build-catalog.py` in the
  app repo from Open Food Facts data. The app downloads and caches this on first
  launch.

Served at: https://dansimone.github.io/familycart-artifacts/extended-catalog.json.gz
